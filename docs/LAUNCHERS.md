# Launchers

WSL launchers:
- `bin/claude-studioos.sh`
- `bin/codex-studioos.sh`
- `bin/gemini-studioos.sh`
- `bin/opencode-studioos.sh`
- `bin/openclaw-studioos.sh`
- `bin/sync-studioos-memory.sh`
- `bin/studio-status.sh`

Windows launchers:
- `launch_studioos_wsl.cmd`
- `launch_claude_studioos.cmd`
- `launch_codex_studioos.cmd`
- `launch_opencode_studioos.cmd`
- `launch_gemini_studioos.cmd`
- `launch_openclaw_studioos.cmd`

First run:
1. Run `bin/sync-studioos-memory.sh` once.
2. Start the app services if needed.
3. Launch your agent of choice from StudioOS.
