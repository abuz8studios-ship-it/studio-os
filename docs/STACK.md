# Stack Overview

## Control Plane
- Chrome Council Extension: subscription-backed specialist input
- Worker Router: bounded delegation and clean OpenClaw path
- Studio MVP: production packet generation and model routing

## Protected Memory Plane
- OpenClaw gateway and SQLite memory stores

## Generation Plane
- Ollama on Windows
- ComfyUI on Windows
- AvatarStack on Windows

## Collaboration Rule
All agents should start from StudioOS and treat it as the shared project root, while leaving external system memory and service configs intact unless explicitly directed.
